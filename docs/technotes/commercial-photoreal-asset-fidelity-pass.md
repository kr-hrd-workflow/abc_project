# Commercial Photoreal Asset Fidelity Pass Evidence

## What changed

This pass upgrades the Unreal renderer from procedural proxy detail toward a commercial-fidelity asset layer while staying fully legal and reproducible.

## Asset source policy

Used assets are project-authored/generated only:

- Procedural texture sheets generated by `tools/asset-pipeline/create_commercial_texture_kit.py`.
- Procedural FBX mesh proxies generated by Blender through `tools/asset-pipeline/create_photoreal_kit.py`.
- No scraped Marketplace/Fab/Megascans assets were committed.
- Licensed asset pack seam remains `/Game/CommercialPhotorealKit` and `/Game/PhotorealKit`.

## Added scene fidelity layer

`generate_city_scene.py` now runs a `spawn_commercial_fidelity_pass(...)` that adds:

- wet asphalt material overlays,
- slabbed sidewalk material overlays,
- worn lane-marking overlays,
- directional arrows,
- manholes with radial grooves,
- storm-drain grates,
- individual curb stones,
- asphalt crack strips,
- textured facade skins,

- traffic cones,

## Upgraded Blender mesh proxies

`create_photoreal_kit.py` now generates smoother FBX replacements for existing mesh names:

- rounded/beveled sedan body,
- torus tires and wheel hubs,
- sedan mirrors, grille, door cut lines,
- bus individual windows, door outlines, grille, rounded tires,
- traffic signal lens visors,
- multi-lobe street tree canopies,
- retained CCTV, streetlight, bollard, wet-road decal assets.

## Visual assessment

The pass visibly improves:

- road reflections,
- worn markings,
- vehicle edges/details,
- signal hardware,
- tree silhouettes,
- curb/roadside detail density,
- city-specific regulatory/street-detail surfaces.

Important limitation: this is still a legal, project-authored procedural fidelity layer. True commercial/AAA scanned realism requires licensed asset packs such as city environment kits, scanned roads/curbs, production vehicles, Megascans/Fab materials, and art-directed lighting/camera work. The repo is now structured so those can be swapped into `/Game/CommercialPhotorealKit` without changing dashboard/API architecture.
