## Required Boundaries

- [ ] Truth source label is visible and matches the details JSON.
- [ ] The stage does not claim real signal control.
- [ ] Asset license and provenance check passed.
- [ ] Generated-output hygiene was checked and unrelated artifacts were not promoted.
- [ ] Remaining blocked tooling, if any, is named with exact missing commands.

## Post-Stage-6 Source And Telemetry Gates

- [ ] Source mode is one of `simulation_snapshot_fixture`, `sumo_traci`, `sumo_libsumo`, `sumo_last_good`, or explicitly labeled fixture fallback after live failure.
- [ ] Fixture mode is documented as intentional and supported, not hidden as live SUMO truth.
- [ ] `sumo_last_good` or any stale frame shows an operator-visible stale/degraded label.
- [ ] Details JSON records frame age, network latency, sim-to-render delay, authoritative Hz, authoritative tick drift, frame staleness, fallback/stale reason, signal state, FPS/frame-time performance, normal and peak draw calls, visible vehicle count, and shadow caster count.
- [ ] Browser proof includes desktop, mobile, canvas-only, and WebGL-off fallback artifacts generated by the same successful verifier run.
- [ ] Visual-scenario proof covers day/high, night/high, rain/high, rain/low fallback, mobile/rain/high, WebGL-off fallback, and canvas-only/nonblank proof, or stops with explicit integration notes for missing renderer-owned scenario attrs.
- [ ] Details JSON records quality preset, postFX enabled/chain, planar reflection state, weather particle state, high-quality vehicle count, shadow caster count, draw calls, frame time, visible vehicles, texture-memory estimate or explicit missing reason, and source/stale/fallback labels.
- [ ] No horizontal overflow evidence is present in `artifacts/r3f-dashboard-details.json`.
- [ ] Stop if the verifier reports blank canvas, source-label mismatch, stale-live-without-label, missing telemetry, missing signal proof, draw-call breach, shadow-caster breach, or overflow.
- [ ] Stop if `verify:r3f-performance` reports missing PostFX state, missing reflection state, a draw-call breach, missing visible vehicle count, or stale source without a visible stale/degraded label.

## Asset And External Tooling Gates

- [ ] Manifest entries include source/license/authorship, units, PBR channel coverage, LOD, texture/triangle/file budgets, compression status, and provenance evidence path.
- [ ] No asset with unclear redistribution rights is shipped.
- [ ] Poly Haven CC0 is preferred for future HDRI/tileable texture additions.
- [ ] Fab/Megascans terms are checked for this repo and redistribution path before use.
- [ ] Sketchfab assets are rejected unless commercial use, modification, and redistribution are explicitly allowed and recorded.
- [ ] Stop before adding SUMO/libsumo/TraCI, Blender, glTF Transform, meshopt/gltfpack, KTX2 encoders, or asset downloads unless the user approves the install/source.
